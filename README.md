 Flatora



Flatora is a website that helps people new to Karachi find flats, apartments, boys hostels and girls hostels in one place.

> Current stage: static website made with **HTML and CSS only** (no JavaScript, no backend). All data is dummy.

 Users

- **Tenant:** searches properties and sends requests
- **Broker:** adds properties and accepts or rejects requests
- **Admin:** approves brokers and removes fake listings

 Pages (10)

Home, Login/Sign up, Property Listings, Search Results, Property Details, My Requests, Broker Dashboard, Add Property, Admin Dashboard, Contact/About.

 How to Run

Download the project and double-click `index.html`.
